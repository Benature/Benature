### AI agents & knowledge tools

- [PupPeT](https://github.com/Benature/puppet): a local desktop Agent workspace for creating and editing HTML slide decks.
- [Pi Auto Review](https://github.com/Benature/pi-auto-review): regex rules plus optional LLM review for Pi's `bash` tool calls.
- [Cola Nowledge Mem Plugin](https://github.com/Benature/cola-plugin-nowledge-mem): memory, recall, and conversation capture for Cola.
- [Agent Skills](https://github.com/Benature/agent-skills): an OmniBox API skill for saving and querying knowledge-base resources.
- [Zotero Parent Item Generator](https://github.com/Benature/zotero-plugin-generate-parent-item-by-ai): generate parent-item metadata for standalone PDF attachments with AI.
- [Claude Code Monitor Lark](https://github.com/Benature/claude-code-monitor-lark): monitor Claude account/API usage and send Lark notifications.
